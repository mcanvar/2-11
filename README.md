# 2048 Game (Nuxt 3 + Tailwind CSS)

A modern, responsive implementation of the 2048 game using Nuxt 3 and Tailwind CSS.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) to play!

---

- Keyboard and touch support
- Clean, mobile-friendly UI
- Built with Nuxt 3 and Tailwind CSS

Enjoy!
